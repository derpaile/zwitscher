# Zwitscher

Eine vollständige, lokal laufende Web-App zum spielerischen Lernen heimischer Vogelstimmen.

## Start

Im Projektordner einen lokalen Webserver starten:

```bash
python3 -m http.server 4173
```

Danach `http://localhost:4173` öffnen. Die echten Vogelstimmen stammen von Wikimedia Commons. Lebensräume lassen sich in den Einstellungen für spätere Offline-Runden herunterladen.

## Enthalten

- 36 heimische Arten mit mehreren Aufnahmevarianten
- sechs Spielmodi: freie Runde, Lerntrainer, Morgendämmerung, Überleben, Morgenchor und Spurenleser
- Tagesaufgabe, Lebensraum-Expeditionen und saisonale bzw. regionale Auswahl
- drei Schwierigkeitsgrade bis zur freien Texteingabe
- adaptives Wiederholen, Meisterschaftsstufen, Statistiken, Verwechslungen und Abzeichen
- Vogelbuch, Artenporträts, A/B-Vergleich, verlangsamtes Hören und Frequenzbild
- lokales Feldtagebuch mit optionalen eigenen Audioaufnahmen
- räumliches Hören, Wetteratmosphäre, hoher Kontrast, große Schrift und entspannter Lernmodus
- installierbare PWA mit Offline-Paketen; sämtliche persönlichen Daten bleiben im Browser
